# Progetto Clips Wumpus

Agente CLIPS modulare per il problema del Wumpus, con due strategie:

- `ingenua`
- `inferenziale`

## Requisiti

L'ambiente virtuale è già presente in `venv` e contiene `clipspy`.

## Test rapido locale

```bash
source venv/bin/activate
python test_agent.py
```

## Uso con il simulatore

Quando hai disponibile il simulatore Python, avvia l'agente puntando `agent.clp` come file dell'agente.
